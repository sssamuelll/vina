Key Behaviors

Snap-to-Edge

Mouse within 20px of any edge → edge highlights. Click places trim at closest parametric t position. Same algorithm as notch tool.

Snap-to-Point

Existing construction points and edge endpoints attract the cursor. Holding Shift snaps to nearest point within 15px.

Mirror to Symmetric

Right-click placed trim → "Mirror to Linked Piece". Auto-finds piece with matching linkedPieceId + linkMode='symmetry'. Creates mirrored trims.

Trim Library Dropdown

23 presets grouped by type (Buttons, Zippers, Snaps...). Search/filter. Shows icon, name, size, material. Select to set active trim for placement.
