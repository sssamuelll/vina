# i18n Phase 0 (Core, Extended) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the i18n core of Vina (locale state, catalogs, number formatting, the Language control, key names, pseudo-locale) and every gate and tool the later phases rely on (lint ratchet, translation lock, glossary test, review document, hooks, baselines, launch gate), without changing anything María sees.

**Architecture:** A zero-dependency `src/i18n/` module: `locale.ts` holds the active locale outside Redux and persists it in `localStorage`; typed TypeScript catalogs (`en` source, `es`, `de`) are read through `t()` / `useT()`; `format.ts` owns every person-facing number. Gates are local ESLint rules, vitest ratchets, a JSON lock hashed from the catalogs' AST, Husky hooks and Playwright specs, following the repository's existing ratchet pattern (`vina/conversion-espacio-de-pieza` + `pieceSpace.trinquete.test.ts`).

**Tech Stack:** TypeScript 5.6, React 19, Redux Toolkit, Vite, Vitest 4 + jsdom + Testing Library (`fireEvent`, no `user-event`), ESLint 9 flat config with typescript-eslint, Playwright 1.58, Husky 9, Node scripts (`.mjs`) that load `typescript` from `node_modules`.

**Spec:** `docs/superpowers/specs/2026-09-29-i18n-design.md` (approved through § 14.2 on 2026-10-20). Phase 0 is § 9.2 "Phase 0 output". The plan argues from the spec; read the sections each task cites.

## Review Focus

1. **An existing install whose storage is blocked or throws** (private window, quota): `detectLocale()` must still return a locale from `navigator.languages`, and `setLocale()` must not throw. → Task 4, test "storage unavailable".
2. **`?lang=` in odd shapes:** `?lang=DE`, `?lang=de-AT`, `?lang=`, `?foo=1&lang=de#x`. The first two are unsupported and only removed; other parameters and the hash survive the strip. → Task 4, test "lang parameter shapes".
3. **Numbers pasted from elsewhere:** `" 12,5 mm"` (no-break spaces) with suffix `mm` is 12.5; a `NumericField` whose `value` is `NaN` shows an empty draft and commits nothing until a valid entry. → Task 5 and Task 10.
4. **Language switch with mounted components:** every `useT()` subscriber re-renders once, and unmounting (StrictMode double mount included) leaves no listener behind. → Task 6, test "useT unsubscribes".
5. **Pseudo-locale leaking to real users:** `?locale=pseudo` is ignored in a production build and never written to `vina-locale`. → Task 4, test "pseudo only in development".

### Task 5: Number formatting and parsing

**Files:**
- Create: `src/i18n/format.ts`
- Test: `src/i18n/__tests__/format.test.ts`, `src/i18n/__tests__/format.importOrder.test.ts`

**Interfaces:**
- Consumes: `getLocale`, `Locale` from `./locale` (and nothing from `./index`, § 5.1).
- Produces:

```ts
export type PluralForms = { other: string } & Partial<Record<Intl.LDMLPluralRule, string>>;
export function formatNumber(value: number, opts: { decimals: number; trim?: boolean }, locale?: Locale): string;
export function formatCount(n: number, locale?: Locale): string;
export function parseNumber(text: string, opts?: { suffix?: string | readonly string[] }): number | null;
export function toMachine(n: number, decimals: number): string; // n.toFixed(decimals), for machine output
export function helpers(locale: Locale): {
  num: (x: number, decimals: number, opts?: { trim?: boolean }) => string;
  plural: (n: number, forms: PluralForms) => string;
};
```

- `formatNumber`:
  - wraps a cached `Intl.NumberFormat(locale, { useGrouping: false, minimumFractionDigits: d, maximumFractionDigits: d, signDisplay: 'negative' })`, cast to `Intl.NumberFormatOptions` because the ES2020 lib lacks `'negative'`;
  - `trim` sets the minimum to 0;
  - non-finite values return `String(value)`.
- `formatCount` uses the locale's default grouping.
- `parseNumber` follows the grammar of `parseMedida.ts:3` (optional ASCII or U+2212 minus, digits, at most one `.` or `,` followed by digits), trims with `String.prototype.trim` (which removes U+00A0) and strips one trailing `suffix` after optional spaces.

- [ ] **Step 1: Write the failing tests** with the spec's values (§ 8.2):
  - the parity grid: integers, 0, values with up to 3 decimals, negatives, `decimals` 0–3, minus the three classes. `en` must equal `x.toFixed(n)`; `es` and `de` must equal it with `,` for `.`;
  - named differences, each also with its comma in `es` and `de`: 1.005 at 2 → "1.01", 1.45 at 1 → "1.5", −0.04 at 1 → "0.0", `NaN` → "NaN", `Infinity` → "Infinity";
  - `trim`: 12 → "12", 12.5 → "12,5" in `es`;
  - `formatCount`: 29338 is "29.338" in `es` and `de` and "29,338" in `en`; 1200 is "1200" in `es` and "1.200" in `de`;
  - `parseNumber`:
    - "12,5" → 12.5, "12.5" → 12.5, "−12,5" → −12.5;
    - "1.500" → 1.5, "1,500" → 1.5;
    - `null` for "1.250,50", "1,250.50", "1e3", "+5", ".5", "12.", "12 cm" with suffix `'mm'`, and "";
    - "12 mm" with suffix `'mm'` → 12;
    - " 12,5 mm" with suffix `'mm'` → 12.5;
  - the round trip, in every locale, with and without `trim`: `parseNumber(formatNumber(x, { decimals: d }))` is x rounded to d;
  - `helpers('de').num(12.3456, 1)` is "12,3" while the active locale is `en`;

```js
// lock-core.mjs
export function readCatalog(locale, root = 'src/i18n'): Map<string, Entry>;
// Entry = { hash: string; text: string; isFunction: boolean; sameAsEn: string | null;
//           glossaryExempt: Array<{ term: string; reason: string }>; foreignRefs: string[] }
// Throws on a spread or computed key ("cannot walk <file>:<line>").
```

- `lock.json` shape: `{ "_doc": string, "entries": { "<area.key>": { "en"|"es"|"de": Record } } }`, where `Record = { hash, sourceHash?, esHash?, reviewedBy, reviewedAt, reviewedHash?, signed?, reason? }`.
- **States** (§ 7.3):
  - `unstamped`: no record;
  - `untranslated`: `es`/`de` text identical to `en` with no `same-as-en`;
  - `stale`: `sourceHash` ≠ the current `en` hash, or `esHash` ≠ the current `es` hash for a key whose `es` is `signed`;

- **`stamp`:**
  - writes `hash` and `sourceHash`, and `esHash` when `es` is `signed`;
  - an area is accepted only for never-stamped entries;
  - a stale record whose own `hash` did not change since its last stamp needs `reason`, one key at a time;
  - it never sets `reviewedBy`.
- **CLI:**
  - `npm run i18n:lock` prints counts per area and locale, and exits 1 on any `unstamped`, `untranslated` or `stale`;
  - `-- --stamp <target> [--reason "…"]` writes the lock;
  - `-- --launch` also exits 1 on `unreviewed` for `SHIPPED_LOCALES`.
