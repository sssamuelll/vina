# OpenClo.ai — Core Engine Spec (v0.5)

## Overview

The core engine is the deterministic middleware between **Semantic Pattern Definition** and **3D Visualization/Simulation**. It operates as a reactive pipeline that transforms intent into high-fidelity physical geometry.

1. **Semantic Interpretation** — Transform graph-based pattern definitions into 2D geometry.
2. **Professional Meshing** — Convert 2D vector outlines into simulation-ready triangle meshes (CDT).
3. **Virtual Assembly** — Execute virtual seam connections using arc-length mapping.
4. **Reactive Pipeline** — Propagate measurement changes from the Copilot or UI to the 3D drape in near-real-time.

## 1. Semantic Pattern Representation ✅ COMPLETE (v0.5)

### Internal Model

We use a hybrid **Semantic Graph Overlay** on top of a precise PathCommand system.

```typescript
PatternPiece
├── outline: PathCommand[]       — Bezier path (M/L/C/Q/Z)
├── internals: InternalLine[]    — Darts, grainlines, notches, fold-lines (Semantic labels)
├── edges: SemanticEdge[]        — Named segments (Armhole, Shoulder, Hem)
├── category: PieceCategory      — Bodice, Sleeve, Skirt, etc.
├── side: PieceSide              — Front, Back, Left, Right
├── seamAllowance: number        — mm offset for industrial output
└── fabricId: string             — Physical fabric assignment
```

### Parametric Template System

Patterns are generated by **Semantic Skills** that use body measurements and tailoring logic:
- **Bodice (front/back)**: Aldrich/Müller/Gilewska methods implemented.
- **Sleeves, Skirts, Pants, Collars**: Full parametric generation with 35+ construction steps.

## 2. Professional Meshing Pipeline (2D → 3D) ✅ COMPLETE (v0.5)

To ensure simulation stability, we use a **Constrained Delaunay Triangulation (CDT)** pipeline with adaptive subdivision.

### The Pipeline
1. **Adaptive Tessellation**: Bezier curves are converted to points. Straight edges are subdivided every 15mm; curves use higher density based on curvature.
2. **PSLG Cleaning**: `clean-pslg` resolves T-junctions and self-intersections.
3. **CDT Triangulation**: `cdt2d` generates high-quality triangles (min angle > 20°), ensuring the mesh can handle the extreme shear and stretch of cloth simulation.
4. **Dart/Notch Integration**: Internal lines are treated as constrained edges, allowing darts to fold accurately in 3D.

## 3. Virtual Assembly (Seams) ✅ COMPLETE (v0.5)

OpenClo.ai uses an **Arc-Length Parameterization** model for sewing, allowing pieces with different vertex counts to be joined smoothly.

### Seam Model
- **Topology Matching**: Edges are mapped to a normalized `[0, 1]` parameter space.
- **Vertex-to-Vertex Constraints**: The solver generates distance constraints between corresponding parameter points on Piece A and Piece B.
- **Shrink-to-Fit**: Seams start with a 3D distance and gradually shrink to zero rest-length during the first frames of simulation (the "sewing phase").

## 4. Reactive Pipeline Flow ⚡ COMPLETE (v0.5)

The entire pipeline is reactive and off-threaded via **Web Workers**:

```
Measurement Change (e.g., Waist +2cm)
    ↓
Semantic Skill re-runs → Updated Graph/Outline
    ↓
Meshing Worker → CDT Triangulation (approx. 45ms)
    ↓
Placement Service → Wraps pieces around Avatar (Tangent Plane Mapping)
    ↓
XPBD Solver (Wasm) → Dynamic Draping (60fps)
```

**Performance:** Measurement update to 3D visual feedback takes < 150ms on modern hardware.

## 5. Industrial Interop (Export) ✅ COMPLETE (v0.5)

- **DXF (ASTM D6673)**: Native export with SPLINE support for industrial cutters.
- **OBJ**: 3D mesh export with UV mapping for external rendering (Blender/Maya).
- **PDF**: Printable cut layouts with grainlines and notches.
