# OpenClo Roadmap — Path to v1.0 🚀

**OpenClo** is currently in **Phase 2: Architectural Consolidation (v0.6.0+)**.
Our goal is to reach **v1.0.0 (Production Ready)** by Q2 2026.

---

## [Current Phase] v0.7.x — Precision & UX Polish (March 2026)
*Focus: Refined editing tools and ergonomic drafting.*

- [ ] **3D Navigation Pro**: Full orbital control with industry-standard shortcuts (CLO3D/Blender).
- [ ] **2D Display Bar**: Context-sensitive floating toolbar for rapid drafting.
- [ ] **Linked Editing**: Symmetric pattern propagation (left sleeve changes sync with right).
- [ ] **DXF High-Fidelity**: Complete ingestion of notches, grading, and internal lines from legacy CAD.
- [ ] **Simulation Snapshots**: Compare different fabric draping states in parallel.

## [Next Phase] v0.8.x — Collaboration & Enterprise (April 2026)
*Focus: Team workflows and industrial validation.*

- [ ] **Multi-User Sync**: Real-time collaborative drafting (Figma-style).
- [ ] **Advanced Fabric Lab**: Calibration tool to import real-world fabric physical data.
- [ ] **Avatar Morphing**: Full parametric avatar with auto-grading integration.
- [ ] **Plugin Marketplace Beta**: Community-contributed skills and pattern templates.

## [The Milestone] v1.0.0 — Production Ready (Q2 2026) 🏁
*Focus: Stabilization, Security, and Final Interop.*

- [ ] **Stability Guardrails**: Deterministic collision resolution for complex multi-layered garments.
- [ ] **Full Interop**: Bidirectional support for CLO3D (.zprj) and Gerber (.tmp).
- [ ] **Security Revamp**: Secure sandboxing for community plugins and encrypted design storage.
- [ ] **OpenClo Cloud**: Global design repository for sharing open-source pattern assets.

---

## Long-term Vision
- **Generative Pattern Synthesis**: Natural language to tech-pack generation.
- **AR/VR Fitting**: Virtual try-on integration for e-commerce.
- **Eco-Optimizer**: Real-time nesting to minimize fabric waste for sustainable production.
